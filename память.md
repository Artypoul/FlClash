## Принятые решения

- На новой установке включать TUN и автоматическую маршрутизацию, не перезаписывать существующие настройки.
- Внешний API по умолчанию оставлять закрытым.
- После успешного импорта выбирать и запускать профиль с сохранением приоритета более поздней остановки.
- Правило `.ru → DIRECT` создавать только для новой базы; пользователь может его изменить.
- Пять китайских исключений удалены из исходных правил и старых настроек однократным обновлением. Повторно добавленные пользователем исключения не удалять при каждом запуске.
- Firebase Analytics и Crashlytics удалены. Локальная обработка сбоев сохранена.
- Проверку качества IP через внешние сервисы оставить: Артём явно исключил её из удаления.
- QR-сканер пока оставить с Google ML Kit: Артём явно выбрал сохранение. Нельзя утверждать, что в приложении полностью отсутствует сторонняя диагностика; исключение описано в соглашении.
- Принятие соглашения — одна кнопка «Согласен», без проверки прокрутки и повторения фразы.
- На простом экране — одна большая кнопка подключения и компактное добавление конфигурации, без переключателя самого быстрого сервера.
- Светлая тема по умолчанию. В персональной сборке Android/Windows один раз включать светлую тему и подключение при запуске; последующие ручные настройки сохранять.
- Подписка персональной сборки задаётся только через `BOOTSTRAP_SUBSCRIPTION_URL`; импортировать и запускать после сохранения, без повторного добавления после удаления пользователем.
- В «О приложении» и соглашении — бесплатный некоммерческий продукт, созданный ради юмора; исходные лицензии сохранять.

## Открытые вопросы

- После первого системного разрешения VPN на Android пользователь наблюдал необходимость повторного включения. Отдельного исправления этого сценария пока нет; нужен журнал с телефона и проверка на устройстве.
- Персональный сборщик GitHub Actions обсуждался, но workflow для передачи подписки и выдачи персонального установщика не реализован.
- Персональные APK/Windows-сборки и временные параметры сборки не включать в публичный Git. Проверка файлов сборки не заменяет проверку на реальном Android-устройстве.

- Перед `b7fc448` прошли получение зависимостей, анализатор и 225 целевых тестов Flutter; состав коммита проверен отдельно от посторонних правок.

- Аудит кода и зависимостей не доказывает факт прежней передачи данных. Отдельный перехват сетевого трафика для такого доказательства не выполнялся.
- Результат локальных проверок не означает публикацию релиза, установку или проверку пользовательского устройства.

## Как обновлять память

Сохранять проверенные решения, рабочие ограничения и открытые задачи в рамках разрешённой работы. После изменений сверять файлы и коммиты; не выдавать устаревший снимок за текущее состояние.
Не записывать секреты или содержимое подписок. Правила скиллов и полномочия на commit, push, merge и публикацию определяются отдельно, а не этим файлом.
