# Память проекта Flashco

Снимок подтверждённого контекста на 2026-10-16. История изменений — в [history.md](history.md).
Этот файл помогает продолжать работу и не заменяет правила [AGENTS.md](AGENTS.md) и каталог `.agents/`.
Перед новой задачей сверять сведения с текущим кодом и состоянием Git.

## Проект и рабочая точка

- Репозиторий: `D:\GitHub\Flashco`.
- Flashco — клиент прокси на Flutter на основе FlClash и ядра mihomo / Clash.Meta.
- Ветка на момент записи: `codex/upstream-v0.9.0`.
- Последний подтверждённый локальный коммит: `b7fc448` — удаление Analytics/Crashlytics, очистка исключений и упрощение соглашения.
- Основа обновлена до FlClash v0.9.0 в `dad4c49`; база профилей использует схему 20. Версия миграции настроек приложения — 2; это отдельный счётчик.

## Принятые решения

- На новой установке включать TUN и автоматическую маршрутизацию, не перезаписывать существующие настройки.
- Внешний API по умолчанию оставлять закрытым.
- После успешного импорта выбирать и запускать профиль с сохранением приоритета более поздней остановки.
- Правило `.ru → DIRECT` создавать только для новой базы; пользователь может его изменить.
- Пять китайских исключений удалены из исходных правил и старых настроек однократным обновлением. Повторно добавленные пользователем исключения не удалять при каждом запуске.
- Firebase Analytics и Crashlytics удалены. Локальная обработка сбоев сохранена.
- Проверку качества IP через внешние сервисы оставить: Артём явно исключил её из удаления.
- QR-сканер пока оставить с Google ML Kit: Артём явно выбрал сохранение. Нельзя утверждать, что в приложении полностью отсутствует сторонняя диагностика; исключение описано в соглашении.
- Принятие соглашения — одна кнопка «Согласен», без проверки прокрутки и повторения фразы.

## Незавершённая работа на момент записи

Вне коммита `b7fc448` сохранены отдельные изменения импорта встроенной подписки:

- `lib/bootstrap.dart` — блок запуска импорта на Android.
- `lib/common/constant.dart`, `lib/common/preferences.dart` — параметр сборки и отметка импорта.
- `lib/providers/actions/profiles.dart`, `lib/providers/database.dart` — импорт и ожидание записи.
- `lib/providers/generated/action.g.dart`, `lib/providers/generated/database.g.dart` — связанные изменения генерации.
- `test/providers/bundled_subscription_test.dart` — новый тест, ещё не отслеживается Git.

Эти изменения намеренно не включались в коммит приватности. Не сбрасывать их и не включать в другую задачу автоматически; сначала сверить актуальный diff и полномочия.
Установленное приложение не обновлялось в рамках последних изменений приватности. Проверка на реальном Android-устройстве не проводилась.
